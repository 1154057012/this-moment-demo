# 这一刻 · This Moment

小影「AI与内容创作」笔试概念作品。帮助短途旅行后有零散视频、不熟悉剪辑的用户，通过标记必留片段与一句话意图，整理一条可预览、可修改的回忆短片。

- 网页：https://1154057012.github.io/this-moment-demo/
- 产品说明：[5页PDF](downloads/product-brief.pdf)
- 备用操作视频：[2分30秒MP4](downloads/walkthrough.mp4)

- 素材来源与声音披露：[SOURCES](assets/media/SOURCES.md)

## 如何演示

1. 打开网页，点击「开始这段回忆」。
2. 保留默认8段素材与第4段必留标记，进入意图页。
3. 输入或选择一句关于海边旅行的描述，生成草稿。
4. 播放预览，分别尝试「突出海浪声」「海景短一点」「撤销」「对比初稿」。
5. 下载对应MP4。也可以调整选片或必留片段，按实际素材播放并导出WebM。
6. 展开右侧「评审用·异常状态体验」，尝试读取失败、生成失败与重试。

## 能力边界

- **未接入真实AI模型**。分析与生成进度为模拟，描述仅用于创作意图和草稿标题。
- 完整8段素材且第4段必留：使用已准备的4种MP4版本；30秒基础/声音版、24秒精简/组合版。
- 其他选片或必留片段：实际顺序播放所选视频、动态混音，使用Canvas+MediaRecorder实时导出WebM。导出需要现代Chrome/Edge等支持的浏览器，耗时约等于视频时长。
- 必留片段完整保留。若第3或5段为必留，缩短操作只影响另一段。
- 输入保存在当前浏览器，不会上传。标题未烧录进导出视频。
- Pexels视频原素材无声；示例音轨来自另行加入的CC0海浪录音和原创合成配乐，不能视为素材现场原音。
- 第5题为CapCut功能案例分析。提交者未提供真实个人经历，已在网站和PDF中明确标明，提交前须体验核实。
- 没有进行真实用户调研、A/B实验或效果数据验证；文档中相关内容为假设和验证计划。

## 本地运行

安装Node.js后，在本目录运行：

```sh
npm run dev
```

访问终端显示的本地地址（默认 http://127.0.0.1:5188）。无需安装前端依赖。

```sh
npm test
npm run check
```

## 实现

静态HTML/CSS/ESM，可直接发布GitHub Pages。`core.mjs`为选片、时间线、撤销和校验逻辑；`player.mjs`为播放、混音与导出；`app.mjs`连接界面和状态。素材随站点提供，避免演示依赖第三方媒体外链。

本项目是独立概念提案，非小影官方产品。代码按MIT许可提供；第三方视频与录音按各自来源许可，详见素材说明。AI工具及修改记录公开列出。
